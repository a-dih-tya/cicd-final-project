# Dealer Evaluation System

## Project Overview
The Dealer Evaluation System is a microservices-based web application that displays product details and compares prices offered by different dealers.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Product Details Microservice:** Python
- **Dealer Pricing Microservice:** Node.js
- **Containerization:** Docker
- **Deployment:** Kubernetes

## Key Features
- Display product details.
- Retrieve dealer information.
- Compare prices offered by multiple dealers.
- Use separate microservices for product and dealer data.
- Support containerization and deployment using Docker and Kubernetes.

## Project Objective
The objective is to develop a modular application using microservices architecture to manage product information and dealer pricing efficiently.
